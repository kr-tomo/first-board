# 이미지 교체 안내

게임에 쓰는 그림은 모두 이 폴더의 PNG 파일입니다. 같은 이름으로 덮어쓰거나, `sprites.json` 에서 경로와 좌표를 바꾸면 코드 수정 없이 교체됩니다.
이미지를 불러오지 못하면 게임은 내장 벡터 그림으로 자동 전환됩니다.

## 1. 말: pieces.png
- 256x256 칸을 5열 x 2행으로 배치한 시트입니다 (1280x512, 배경 투명).
- 윗줄은 청룡(파랑), 아랫줄은 주작(빨강)입니다.
- 열 순서: 대장, 백호, 기린, 거북기, 현무.
- 모든 말은 위쪽이 앞인 모습으로 그립니다. `rotateOpponent` 가 true 이면 주작 말은 게임에서 180도 돌려 표시합니다. 주작 말을 이미 뒤집어 그렸다면 false 로 바꾸세요.
- 칸 크기나 열/행 수를 바꾸면 `cols`, `rows`, `cell` 도 같이 고치세요. `frames` 의 값은 [열, 행] 번호이며 0부터 시작합니다.
- 말의 가장자리 그림자는 게임에서 따로 넣으므로 그리지 않아도 됩니다.

## 2. 보드: board.png
- 3:4 비율의 한 장짜리 그림입니다 (900x1200).
- 테두리를 포함한 전체 그림이며, 말이 놓이는 3열 x 4행 칸은 `board.inset` 으로 지정합니다.
  `inset` 은 [왼쪽, 위, 오른쪽, 아래] 여백이며 단위는 이미지 폭/높이에 대한 퍼센트입니다. 기본값 [4, 3, 4, 3] 은 사방 36px 입니다.
- 위쪽 줄은 주작 진영, 아래쪽 줄은 청룡 진영입니다. 진영 색은 그림에 직접 칠합니다.

## 3. 잡은 말 영역: tray-*.png
- `tray-blue-h.png`, `tray-red-h.png`: 화면이 세로일 때 보드 아래와 위에 놓이는 가로 배경 (1200x180).
- `tray-blue-v.png`, `tray-red-v.png`: 화면이 가로일 때 보드 양옆에 놓이는 세로 배경 (240x960).
- 영역 크기에 맞춰 꽉 채워 표시(cover)하므로 가장자리는 잘릴 수 있습니다. 글자가 올라가는 왼쪽(가로)과 위쪽(세로)은 너무 복잡하지 않게 그리세요.

## 캐시
서비스 워커가 파일을 저장해 두므로, 그림을 바꾼 뒤에는 `sw.js` 의 VERSION 값을 올려야 기존 사용자에게 반영됩니다.
